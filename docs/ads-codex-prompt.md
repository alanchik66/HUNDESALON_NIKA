## Задача 1. Asset group — Темы поиска

URL: https://ads.google.com/aw/assetgroup/edit?campaignId=24051075076&assetgroupId=6731829821

1. Найди секцию **«Больше объектов разных типов (0/6)»** — разверни её (клик).
2. Среди объектов (Промоакции, Цены, Чат и т.д.) найди блок с **сигналами/темами поиска**. Если его нет в этом списке — они в настройках кампании: открой настройки кампании (шестерёнка рядом с HUNDESALON_NIKA в списке кампаний) → ищи «Темы поиска» или «Search themes».
3. Добавь два сигнала:
   - `Hundefriseur Leipzig`
   - `Hundepflege Leipzig`
4. Нажми **Сохранить**.

## Задача 3. Конверсии — назначить цели и проверить source

URL: https://ads.google.com/aw/conversions?src=ads_onebox&ocid=8415382946

### 3a. Покупка
1. Найди действие-конверсию **«Покупка»**.
2. Нажми **«Изменить цель»**.
3. Назначь его как **основное действие-конверсию (primary action)** для оптимизации.
4. Сохрани.

### 3b. Отправка формы, Регистрация, Телефон
Для каждого из трёх действий:
1. **«Отправка формы»** → Изменить цель → проверь, что источник = `website` и теги Google Ads на месте.
2. **«Регистрация»** → Изменить цель → проверь, что источник = `website` и теги на месте.
3. **«Телефон»** → Изменить цель → проверь, что источник = `website` и теги на месте.
4. Сохрани изменения.
