# Slack для HUNDESALON NIKA: полная настройка

## Что уже настроено в коде проекта

- Входящие заявки с сайта через `POST /sendmail` отправляются:
  - на email `info@hundesalon-nika.com` через SendPulse;
  - в Slack через `SLACK_WEBHOOK_URL` (если переменная задана).
- Ошибки отправки через SendPulse также отправляются в Slack, чтобы не пропустить инцидент.
- Формат уведомлений в Slack: русский, с полями формы (имя, email, телефон, услуга, дата, время, язык, страница).
- Для проверки вебхука добавлена команда:
  - `npm run slack:test`

## 1) Создать Slack App и webhook (Incoming Webhooks)

1. Откройте страницу создания приложения: https://api.slack.com/apps
2. Нажмите **Create New App**.
3. Выберите **From scratch**.
4. Название: `HUNDESALON_NIKA_SITE`.
5. Выберите ваш Slack Workspace.
6. Откройте раздел **Incoming Webhooks**.
7. Включите переключатель **Activate Incoming Webhooks**.
8. Нажмите **Add New Webhook to Workspace**.
9. Выберите рабочий канал, например `#site-leads`.
10. Подтвердите и скопируйте URL вида:
    - `https://hooks.slack.com/services/...`

## 2) Подключить webhook в окружение проекта

### Локально

Добавьте в `.dev.vars`:

SLACK_WEBHOOK_URL=https://hooks.slack.com/services/XXX/YYY/ZZZ

### Продакшен (Cloudflare Pages)

Cloudflare Pages -> Settings -> Environment variables:

- `SLACK_WEBHOOK_URL` = ваш webhook URL

Важно:
- Название секрета должно быть ровно `SLACK_WEBHOOK_URL`.
- Не создавайте секрет с именем вроде `SLACK_WEBHOOK_URL=https://...`.

## 3) Проверить интеграцию

1. Быстрый тест вебхука:

   npm run slack:test

2. Боевой тест формы:

- Отправьте тестовую заявку с сайта.
- Убедитесь, что письмо пришло на `info@hundesalon-nika.com` и сообщение появилось в Slack.

## 4) Перевод Slack на русский язык

### Веб/десктоп клиент Slack

1. Откройте **Preferences**.
2. Перейдите в **Language & region**.
3. В поле языка выберите **Русский** (если доступен в вашем workspace-клиенте).
4. Перезапустите Slack клиент при необходимости.

Если русский не отображается:
- обновите клиент Slack до последней версии;
- проверьте языковые ограничения workspace (на некоторых тарифах/политиках админ ограничивает локали);
- временно используйте английский интерфейс, уведомления от сайта всё равно будут на русском.

## 5) Рекомендации по профессиональной эксплуатации

- Создайте отдельный канал для лидов: `#site-leads`.
- Ограничьте доступ к каналу только ответственным менеджерам.
- Закрепите в канале сообщение с регламентом ответа клиенту (SLA).
- Добавьте второй webhook для резервного канала при необходимости.
- Храните webhook только в секретах, не коммитьте его в git.

## 6) Что настроено отдельно

- `tools/post-deploy.mjs` уже умеет отправлять уведомления о деплое в Slack через тот же `SLACK_WEBHOOK_URL`.

Итог: после добавления секрета `SLACK_WEBHOOK_URL` у вас будет единая Slack-интеграция для заявок с сайта и для деплой-статусов.
