# GitLens 18 — ежедневный цикл (2 минуты)

Цель: быстро понять состояние ветки, не пропустить блокеры и подготовить чистые коммиты.

## 0:00-0:20 — Быстрый статус

1. Открой Commit Graph.
2. Включи фокус на своей ветке (Focus Branch).
3. Проверь WIP-строку: есть ли изменения, конфликты, ahead/behind.

## 0:20-0:50 — Проверка агентных задач

1. Открой боковую панель Agent Sessions.
2. Если есть статус Needs Input, обработай его первым.
3. При нескольких сессиях переключи режим на Tree и сгруппируй по worktree.

## 0:50-1:20 — Качество перед коммитом

1. В details panel переключись в Review mode.
2. Пройди найденные замечания по severity.
3. Исправь критичные/высокие риски до коммита.

## 1:20-1:50 — Сборка коммитов

1. Переключись в Compose mode.
2. Разбей WIP на логические коммиты (по задаче/фиче, не по типу файла).
3. Проверь diffs в multi-diff перед подтверждением.

## 1:50-2:00 — Финальная проверка

1. Проверь Launchpad: нет ли новых PR/блокеров.
2. Убедись, что нужная ветка запушена и готова к PR.

## Правила для этого репозитория

1. Worktree-first для параллельных задач: одна задача = одно рабочее дерево.
2. Не смешивать hotfix и UI/SEO правки в один коммит.
3. Перед деплоем следовать проектному gate: `npm run validate`.

## Минимальный операционный стандарт

1. Каждый рабочий цикл начинается с Commit Graph.
2. Любой коммит из WIP проходит Review mode.
3. Любая серия изменений в 3+ файлов идет через Compose mode.
4. Needs Input в Agent Sessions обрабатывается в приоритете.
