## 📝 Использование

### 1. Обновление изображений

Изображения уже подключены через папку `assets/images/before-after/`. Чтобы заменить или добавить работу, положите новый JPEG/WebP в эту папку и обновите объект в `assets/js/before-after.js`:

```javascript
const beforeAfterItems = {
  de: [
    {
      beforeImage: beforeAfterImage('new-before.jpg'),
      afterImage: beforeAfterImage('new-after.jpg'),
      beforeLabel: 'VORHER',
      afterLabel: 'NACHHER',
      badge: 'Schnitt',
      category: 'haircut',
      title: 'Pudel-Lady elegante Transformation',
      description: 'Komplette Pflege mit Modell-Schnitt'
    },
    // Добавьте больше примеров...
  ]
};
```

### 2. Категории

Используйте эти категории для фильтрации:
- `haircut` — Стрижки
- `creative` — Креативное груминг  
- `cats` — Кошки

### 3. Добавление новых примеров

Скопируйте структуру объекта и измените данные:

```javascript
{
  beforeImage: 'path/to/before.jpg',
  afterImage: 'path/to/after.jpg',
  beforeLabel: 'ДО',
  afterLabel: 'ПОСЛЕ',
  badge: 'Категория',
  category: 'haircut', // haircut, creative, или cats
  title: 'Заголовок примера',
  description: 'Краткое описание'
}
```

## 🖼️ Рекомендации по изображениям

## 🛠️ Настройка

### Изменение позиций слайдера

В `before-after.js` измените начальную позицию:

```javascript
this.sliderPosition = 50; // 50% = по центру
```

### Скорость анимации

В `page-modules.css` измените:

```css
.before-after-after {
  transition: clip-path 0.1s ease-out; /* Измените 0.1s */
}
```

### Размер слайдера

В CSS найдите и измените:

```css
.before-after-slider::before {
  width: 44px;  /* Размер круга */
  height: 44px;
}
```

## 🐛 Устранение проблем

### Изображения не отображаются
1. Проверьте пути к файлам
2. Убедитесь, что файлы существуют
3. Проверьте права доступа к файлам

### Слайдер не работает
1. Проверьте консоль браузера на ошибки JavaScript
2. Убедитесь, что `before-after.js` загружается
3. Проверьте, что контейнер `#before-after-gallery` существует

### Фильтры не реагируют
1. Проверьте, что данные имеют правильные категории
2. Убедитесь, что `category` совпадает с фильтром
3. Проверьте инициализацию галереи
