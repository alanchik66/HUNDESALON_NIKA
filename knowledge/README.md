# HUNDESALON_NIKA Knowledge Vault

This vault is the working memory for the project.

## Use
- Capture decisions, incidents, QA results, and release notes here.
- Keep code facts linked to exact files and dates.
- Prefer short, factual notes over prose.

## Conventions
- One topic per note.
- Use UTC dates in filenames for daily and incident notes.
- Write outcomes first, then evidence.
- Keep private address data out of this vault.
