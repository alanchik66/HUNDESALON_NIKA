# QA

## Minimum checks

- Desktop layout
- Mobile layout
- Locale coverage for `de`, `en`, `ru`, `uk`
- Content correctness
- No duplicate catalog items
- Contact and brand consistency

## Evidence format

- Date
- Surface
- Result
- Screenshot or note
- Follow-up

## Pass criteria

- The fix is visible in the actual UI.
- Locale text matches the selected language.
- No new regression appears in adjacent views.
