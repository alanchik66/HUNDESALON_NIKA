# Загрузка файлов в админке NIKA

Проверено 2026-11-21. См. [[02_Areas/Operations]] и `docs/SITE_ADMIN.md`.

- Бесплатный тариф Cloudflare принимает до 100 МБ в одном запросе. D1 Free ограничивает строку 2 МБ и одну базу 500 МБ. Поэтому в админке файл до 150 МБ передаётся частями по 1 МиБ, а в D1 хранится частями по 256 КиБ. Лимит библиотеки 325 МБ считается по исходным байтам. Кодирование base64 и данные остальных таблиц тоже занимают место в базе. [Workers](https://developers.cloudflare.com/workers/platform/limits/) · [D1](https://developers.cloudflare.com/d1/platform/limits/)
- `functions/_lib/admin-media.js` отдаёт большие файлы потоком, включая запрошенные диапазоны для перемотки. В Workers `FixedLengthStream` сохраняет точный `Content-Length` для потока известного размера. [Документация Cloudflare](https://developers.cloudflare.com/workers/runtime-apis/streams/transformstream/#fixedlengthstream)
- В тесте WebKit на Windows сериализация `Blob` из файла на диске исказила хвост PDF размером 150 МБ. На тех же данных чтение через `File.slice().arrayBuffer()` и отправка `ArrayBuffer` сохранили SHA-256 передаваемой части. Админка читает и передаёт таким способом только текущую часть файла (`assets/js/site-admin.js`).
- Рабочая D1 и тот же серверный код выдержали проверку 21 ноября 2026 года во временном сеансе Cloudflare. Из 144 частей сохранён закрытый MP4 размером 150 000 000 байт. Сверены ответ 404 на сайте для черновика, HTTP 206 для диапазона и SHA-256 полного потока. После теста в базе не осталось черновика и его частей. Отдельно в локальных Chrome и WebKit через интерфейс проверены MP4, PNG и PDF того же размера. [Удалённая разработка в Cloudflare](https://developers.cloudflare.com/workers/local-development/#wrangler-dev---remote-legacy)
- Системное окно выбора файлов на iPhone использует приложение «Файлы». iCloud Drive виден при включённой синхронизации. Google Drive и OneDrive должны быть включены как места хранения. Сайт получает выбранный файл, а доступ к облаку управляется на устройстве. [Поддержка Apple](https://support.apple.com/en-us/102238) · [Google Drive для компьютеров](https://support.google.com/drive/answer/13401938?hl=en)
