# Редактор страниц NIKA

Проверено 2026-11-21. См. [[02_Areas/Operations]] и `docs/SITE_ADMIN.md`.

- `functions/_lib/page-editor-catalog.js` описывает канонические адреса, доступные языки и алиасы. Каталог локальных страниц включает 24 страницы на четырёх языках, меню Telegram на четырёх языках и отдельный англоязычный выбор языка отзывов.
- Черновики в `site_page_editor` отделены от публичного `site_page_copy`. При публикации текущая версия, запись в историю и сброс черновика фиксируются одним пакетом SQL. Ожидаемая ревизия и токен операции защищают от пересечения правок. В истории сохраняются последние 20 публикаций каждой языковой версии. [Семантика D1 batch](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)
- Проверено 2026-11-21 на выпуске `30e4198`. После сохранения переключателя или публикации сайт читает актуальную запись из основной D1 при следующей загрузке. Управляемые документы и ответы медиатеки используют `Cache-Control: private, no-store`, а service worker пропускает запросы к ним напрямую в сеть. `www` перенаправляет на основной домен с сохранением пути и параметров. Уже открытая вкладка получает правки при обновлении. [Сессии Cloudflare D1](https://developers.cloudflare.com/d1/worker-api/d1-database/#withsession) · [Кэширование Cloudflare](https://developers.cloudflare.com/cache/concepts/cache-control/)
- Изменения применяются к полям, которые выделены при сборке. HTML-текст и атрибуты экранируются, адреса редакционных ссылок проверяются отдельно. Предпросмотр проходит через авторизацию владельца и отвечает с `Cache-Control: private, no-store` и `Content-Security-Policy: sandbox`. Проверки сохранения и публикации находятся в `functions/api/admin/page.test.js`.
- Рабочая панель опубликована на отдельном HTTPS-поддомене того же проекта Pages. Cloudflare Access допускает только почту владельца. `site-admin-access.js` заново проверяет подпись, издателя, приложение и почту в токене. Запросы API дополнительно требуют сессию панели. Прямые маршруты панели и её файлы на публичных доменах возвращают 404. Проверено на развёртывании `044d4076` 2026-11-21. [Собственный домен Cloudflare Pages](https://developers.cloudflare.com/pages/configuration/custom-domains/) · [Проверка токена Access](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/)
- При запросе открытых ключей Access в `site-admin-access.js` нужен режим `redirect: 'manual'`. Ответы 3xx отклоняет проверка `response.ok`. В `workerd` с настройками сайта 2026-11-21 предыдущий режим `error` приводил к отказу ещё до отправки запроса, даже с действительной подписью токена владельца. Исправление пропускает действительный тестовый токен и по-прежнему отклоняет неверную подпись, неподходящего владельца и перенаправление. [Fetch Request в Cloudflare Workers](https://developers.cloudflare.com/workers/runtime-apis/request/)
- 2026-11-21 подтверждено, что записи обычных переменных в снимке Pages не совпадали с привязками запущенной функции. После входа Cloudflare сервер возвращал 404 с этапом `origin` в журнале. Четыре настройки Access теперь передаются как секреты Pages. Проверка рабочего выпуска сверяет имена и типы всех пяти `SITE_ADMIN_*` через конфигурацию действующего Worker. Значения секретов в код и журналы не передаются. [Секреты Cloudflare Pages](https://developers.cloudflare.com/pages/functions/bindings/#secrets)
- Отключение онлайн-записи блокирует новые заявки и создание оплаты. Возврат из Stripe по действительной ссылке сохранился для просмотра и обновления статуса уже существующего заказа. Страница проверяет токен через общий модуль оплаты и закрывает страницу от кэша и аналитики. В Chrome и WebKit с профилем iPhone 13 проверена готовая сборка на синтетической базе 2026-11-21.
