# Start Here

This vault is the operating memory for HUNDESALON_NIKA.

## First use
- Capture raw input in `00_Inbox`.
- Turn repeated work into decisions, templates, or checklists.
- Link every non-trivial note back to exact code files or release evidence.

## What lives here
- Project facts
- QA evidence
- Release notes
- Decisions
- Catalog and locale changes
- Asset and brand references

## What stays out
- Secrets
- Cookies
- MFA codes
- Private address data
- Any temporary browser session data

## Daily workflow
- Start with the current project note.
- Create new actionable work in [[01_Projects/HUNDESALON_NIKA/Tasks/README]].
- Add what changed and why.
- Record verification after the fix.
- Move finished items into the decision or release area.
